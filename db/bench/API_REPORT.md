## Выводы

> Раздел написан вручную по этому прогону; `KassirERP.ApiBench` его не генерирует.

- Бэкенд добавляет к скану ≈ 0.2–0.35 мс, к поиску ≈ 0.35–0.45 мс (p50). Из них ≈ 0.16 мс — HTTP и проверка JWT (`/auth/me` без базы).
- Поиск после миграции 0003 — 2.7–3.3 мс через API (до неё было 46–56 мс). Подробно и на базе с втрое большим числом товаров — [SEARCH_REPORT.md](SEARCH_REPORT.md).
- Между Postgres и Npgsql ≈ 0.5–1 мс — сеть с Windows до контейнера Docker и сетевой обмен драйвера; на сервере, где API и Postgres рядом, будет меньше.
